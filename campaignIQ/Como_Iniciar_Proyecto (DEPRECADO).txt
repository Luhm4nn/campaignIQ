INSTRUCCIONES DE SETUP - CampainIQ Backend

1. Clonar el repositorio
   git clone <url-del-repo>
   cd CampainIQ

2. Cambiarse a la rama de trabajo
   git checkout valentino

3. Ir a la carpeta del backend
   cd campaignIQ/backend

4. Crear el entorno virtual (solo la primera vez)
   python -m venv venv

5. Activar el entorno virtual

   En PowerShell:
   .\venv\Scripts\Activate.ps1

   En Git Bash:
   source venv/Scripts/activate

   En Linux/Mac:
   source venv/bin/activate

   (Si PowerShell tira error de permisos, correr antes:
   Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope Process)

   Vas a ver "(venv)" al principio de la línea si se activó bien.

6. Instalar las dependencias
   pip install -r requirements.txt

7. Crear el archivo de variables de entorno
   Copiar .env.example y renombrarlo a .env
   Completar los valores necesarios (credenciales, keys, etc.)

8. Correr el servidor
   uvicorn app.main:app --reload

9. El backend debería quedar corriendo en:
   http://127.0.0.1:8000
